# Симптом → проверка → исправление

| Симптом | Что измерить | Частое исправление |
| --- | --- | --- |
| Скорость как у ракеты | scale, число шагов, amount, w и L | Не считать 30 мировыми м/с; убрать двойной writer/tick |
| Нет разгона при стрейфе | проекция и uncapped w | Использовать full wishspeed в импульсе воздуха |
| В воздухе мгновенно останавливает | кто присваивает velocity/drag | Сохранять импульс, убрать наземное торможение из air-ветки |
| Диагональ быстрее сама по себе | длина исходного ввода | ClampMagnitude(1), сохрани аналоговый диапазон |
| Лунный прыжок | jump impulse, gravity, held lift | Настроить оба источника подъёма, не смешивать GS/миры |
| Проседает скорость при каждом hop | grounded и accepted jump | Решать прыжок до friction, проверить штатный limiter |
| Ходьба после отпускания jump не тормозит | friction branch | Пропускать трение только для разрешённого jump-step |
| Прыжок один раз или через раз | edge/held, время сброса jump count | Защёлкнуть input и соблюдать reset при приземлении |
| Застывает crouch+jump | early return перед gravity/Move | Не пропускать вертикальную физику из-за crouch |
| Встаёт в потолок | shape overlap и self-filter | Проверять standing capsule, сохранить crouch при блоке |
| Урон после серии мелких прыжков | episode ID/apex/timer | Завершать каждое приземление до нового jump |
| Стена не тормозит накопленный импульс | v до/после solver | Вернуть в модель collision-corrected velocity |
| Сеть откатывает позицию | authority, replay, config | Совпадающая серверная/клиентская симуляция |
| UPS вырос втрое без физической разницы | scale HUD | Это смена единиц; согласуй подписи и пороги |
| DLL падает после обновления | hash, ABI, displaced bytes, unwind | Остановить непроверенную установку, восстановить оригинал и исправить причину |

Для разбора полезна запись одного шага: input, grounded_before, jump_accepted, velocity_before, wishspeed, projection, impulse, dt, scale, collision flags, velocity_after. Не записывай каждый кадр без лимита: ограниченный ring buffer или выбранный эпизод легче проверить.
