# UPS-метр

UPS = длина фактической скорости в горизонтальной плоскости, умноженная на scale. Для произвольной гравитации сначала убери компоненту вдоль up. Вертикальный прыжок не добавляет UPS. Если хочется измерять движущуюся платформу отдельно, назови систему отсчёта явно.

Ориентир GoldSrc — [Bunnymod XT DrawSpeedometer](https://github.com/YaLTeR/BunnymodXT/blob/master/BunnymodXT/hud_custom.cpp): горизонтальная скорость цифрами, дробная часть отбрасывается. Спидометр BXT использует игровые спрайты; собственные примеры здесь используют текст/доступный UI-шрифт, без включения чужих спрайтов.

## Читаемое оформление

- Янтарный RGB(255,160,0), тёмная тень, центр внизу.
- Высота цифры около 60 пикселей при 900p/1080p; учитывай DPI/UI scale.
- Для собственного 12×20 сегментного шрифта: scale=clamp(floor(height/300),2,8), высота=20*scale, шаг цифры=14*scale. Это даёт 60 px при 900p и 1080p.
- Дробную часть отбрасывай: 299.99 → 299. Нулевую скорость показывай как 0.
- Ограничение форматирования, например 999999, не меняет физику.

Проверь не только 1920×1080, но и 1600×900, 1280×720, 640×480, 4K. Маленькая оранжевая точка вместо читаемой цифры — повод проверить реальную высоту глифа и двойное масштабирование Canvas/viewport.

В Unity можно использовать uGUI/TMP существующего проекта или тестовый OnGUI; в Unreal — UMG на локальном HUD; в Godot — CanvasLayer+Label. Не создавай виджет заново каждый frame и не рисуй чужих сетевых персонажей. Native IMGUI должен сохранять GUI.color и рисовать только в Repaint.

Превью, построенное из draw-команд, доказывает геометрию примера. Для утверждения «так выглядит в игре» нужен настоящий игровой кадр.
