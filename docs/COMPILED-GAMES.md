# Когда есть только готовая игра

Этот путь не имеет универсального установщика. Сначала проверь доступный для конкретной игры mod SDK, loader или source port и его совместимость. Для одной игры можно встроить формулу в несколько строк скрипта; для другой потребуется отдельное исследование.

## Unity Mono

Установи движок/runtime и поддерживаемую архитектуру loader. Найди управляемый контроллер и метод горизонтальной скорости. Модифицируй только нужную часть через поддерживаемый hook/плагин или проверенную правку assembly. Проверь, что оригинальное ускорение не выполняется второй раз. Версии внешних loaders проверяй по их официальным инструкциям, например [BepInEx](https://docs.bepinex.dev/).

## Unity IL2CPP / native

GameAssembly содержит нативный код. Metadata и бинарник должны относиться к одной сборке. Определи реальные сигнатуры и layout полей; не переносишь RVA из другого exe. Скрытые struct-return параметры меняют распределение аргументов.

При собственном PE/hook решении нужны: оригинал+SHA-256, ожидаемые исходные инструкции, целые границы инструкций, сохранение ABI, корректные относительные переходы, .pdata/unwind для новых функций и восстановление при ошибке. На x64 учитывай shadow space и nonvolatile XMM/GPR. GC handles могут иметь размер указателя; не обрезай их до 32 бит по старой привычке.

Live-обновление выполняй только для распознанной версии: новый код готовится отдельно, проверяются старые immutable-байты, переходы переключаются согласованно, старый код остаётся жить для уже исполняющихся кадров. При недоказанном состоянии готовь файловую установку с перезапуском.

## Unreal export

Наличие .pak не означает доступ к исходному movement component. Найди официальный путь модов/плагинов этой игры, возможности скриптов/Blueprint overrides либо собственный поддерживаемый source port. Совместимость модлоадера, сборки и сетевой модели подтверждается отдельно. Универсальный CMC-патч для всех UE-игр здесь не предполагается.

## Godot export

PCK может содержать ресурсы и скрипты, но это не гарантирует исходный GDScript, права записи или совместимость перепаковки. Если есть mod API — используй его. Если доступен проект — возвращайся к обычному CharacterBody3D. Если доступной точки расширения нет, конкретно сообщи этот факт вместо выдуманной установки.

## Проверяемая установка

Работай на отдельной копии файлов, когда это нужно для сохранения исходника. Проверь точную сборку до изменения. Сделай идемпотентную установку, отказ на неизвестной версии и точный откат на копии. После реального запуска проверь, что изменён именно тот модуль, который загружен процессом. Одинаковое имя файла из временной папки и установленной игры не означает одинаковый путь.

Сетевое отключение не является доказательством причины. Перенос movement не включает произвольные изменения защитных компонентов, прокси или сервера; сетевую совместимость реализуют через совпадающую симуляцию по NETWORKING.md.
