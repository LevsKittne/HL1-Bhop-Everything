# Запросы для ИИ по этапам

Прикладывай весь репозиторий или обеспечь доступ к файлам. Короткий запрос не заменяет доступ к проекту.

## Найти точку движения

```text
Прочитай AGENTS.md. Исследуй <ПУТЬ>, не меняя игру на этом этапе.
Покажи подтверждения движка/версии, название player controller, функцию записи
скорости и функцию коллизий. Укажи ось вверх, единицы, timestep, ввод и владельца
сетевого движения. Выбери маршрут из docs. Если данных нет — скажи, что найти.
Не предлагай адреса или API без проверки сборки/документации.
```

## Реализовать после диагностики

```text
Добавь classic-bhop в найденный контроллер: коэффициенты 10/10, friction=4,
stopspeed=100 GS units/s, air projection=min(wishspeed,30). Импульс воздуха
считай от полного wishspeed. Автопрыжок на удержании назначенной кнопки.
Сохрани базовую скорость, высоту прыжка и штатные коллизии. Не запускай второй
контроллер рядом с первым. Доведи до собираемого результата и проведи проверки.
```

## Слишком быстро

```text
Не подбирай случайный множитель. Сними v_before, wishspeed, projection,
acceleration_impulse, dt и scale в GS units. Сравни с reference/goldsrc.py и
tests/cases.csv. Проверь двойное ускорение, двойной tick и неверные единицы.
Отдельно скажи, включён ли stock limiter 1.7/0.65.
```

## Присед / падение / HUD

```text
Прочитай docs/JUMP-CROUCH-FALL.md и docs/HUD.md. Исправь удержание приседа и
проверку потолка. Короткие bhop-прыжки не должны накапливать урон от падения.
Добавь горизонтальный UPS-метр, размер цифр около 60 px при 900p/1080p.
Изменение отображения не должно менять физическую скорость.
```

## ИИ сказал «готово», но результата нет

```text
Покажи конкретные изменённые файлы, путь готовой сборки, вывод компилятора,
команды тестов и их результаты. Назови непроведённые проверки отдельно.
Если есть необходимые инструменты, продолжай сборку и исправление ошибок.
Если инструмента/доступа нет — назови конкретное препятствие и готовые артефакты.
```

## Сеть откатывает позицию

```text
Найди серверный и клиентский шаг симуляции и формат сохранённого ввода.
Воспроизведи одинаковую последовательность команд с одинаковыми настройками.
Исправь расхождение движения/предсказания. Не объявляй коррекцию доказательством
античита и не заменяй сетевой код отключением проверок.
```
