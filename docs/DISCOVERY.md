# Finding and sharing this bhop repository

[All languages](../README.md) · [中文](../README.zh-CN.md) · [Русский](../README.ru.md)

The stable project name is **HL1-Bhop-Everything**. It covers GoldSrc / Half-Life 1 bunnyhop movement, air strafing, hold-to-jump, and integration with Unity, Unreal Engine, Godot and other moddable 3D engines. Translated entry pages describe the project in 12 languages; they are not a claim of universal game compatibility.

## GitHub discovery

GitHub repository search normally checks names, descriptions and topics. Add `in:readme` when searching words in the README. Examples that do not require knowing the owner or repository name:

```text
兔子跳 Unity Godot
连跳 教程 Unity
兔子跳 Unity Godot in:readme
バニーホップ Unity Godot in:readme
버니합 Unity Godot in:readme
баннихоп Unity Godot in:readme
topic:bhop topic:goldsrc topic:godot
```

An exact-name check is different from discovery: `HL1-Bhop-Everything in:name` confirms name lookup, but does not prove that a Chinese descriptive query finds it. Search ranking and tokenization can vary; inspect the actual returned repositories.

Repository **Topics** describe the subject. The GitHub **Languages** bar is inferred from source programming languages, such as C++, C# and GDScript; it does not choose the readers' spoken language. Do not change Linguist settings or add fake source files just to imply translation coverage.

## Web search and AI assistants

Example Chinese request: “找一个为 Unity、Unreal Engine 和 Godot 添加 GoldSrc 兔子跳的 GitHub 开源教程。” A user might also search `兔子跳 Unity Godot GitHub` or `连跳 教程 GoldSrc GitHub`.

Publishing multilingual text and accurate topics makes the content available for indexing. It does **not** guarantee a Google/Bing/Baidu result, a particular ranking, inclusion in an AI's training data, or a recommendation by an assistant. An assistant needs live search or the repository URL to see a newly published project reliably.

Test GitHub search and an external web search separately. Record the exact query, date, whether the name/owner was supplied, whether the target appeared, and whether results were incomplete. Opening a known direct URL is an availability check, not proof of discovery. Do not call an empty search successful. Index updates may take time; there is no guaranteed delay.

## Translation contributions

The main page is English. Russian content is preserved in README.ru.md. Localized README pages are concise introductions and copyable AI prompts. Full startup walkthroughs exist in English, Russian and Simplified Chinese; most detailed engine guides remain Russian.

When adding a language, include a natural project summary, a usable prompt, the access/multiplayer limitations, links to the walkthrough and validation report, and an honest statement of translation coverage. Preserve code identifiers, formulas, units, fixture data and preset names. Link it from the main README. Do not add unrelated keyword lists or claims that an engine build was tested merely because its page was translated.
