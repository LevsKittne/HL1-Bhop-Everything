# HL1-Bhop-Everything — حركة باني هوب والقفز المتتابع بأسلوب GoldSrc

[English / Languages / 多语言 / Языки](README.md) · **العربية**

دليل لإضافة باني هوب (bunnyhop / bhop) والقفز التلقائي والتسارع في الهواء إلى ألعاب ثلاثية الأبعاد قابلة للتعديل بمساعدة مساعد برمجة بالذكاء الاصطناعي. يتضمن إرشادات Unity وUnreal Engine وGodot، وأمثلة C++ وC# وGDScript واختبارات مشتركة.

## البدء

نزّل المستودع وافتحه في مساعد يستطيع قراءة الملفات وتعديلها، ثم استبدل <PATH> بالمسار الفعلي للعبة أو المشروع.

[دليل البدء بالإنجليزية](docs/START-HERE.en.md)

```text
اقرأ AGENTS.md وdocs/START-HERE.en.md.
أضف classic-bhop إلى اللعبة أو المشروع في <PATH> مع القفز التلقائي عند
الاستمرار بالضغط على زر القفز، ومقياس واضح للسرعة الأفقية بوحدة UPS.
حدد أولاً المحرك والوحدات والكود المسؤول عن كتابة السرعة والجهة التي تتحكم بالحركة.
ادمج التعديل في المتحكم الحالي، مع الحفاظ على ارتفاع القفزة الطبيعي والتصادمات
وفحص المساحة عند الانحناء وأزرار التحكم. ترجم دليل المحرك إلى العربية مع حفظ المعادلات والوحدات.
نفّذ التعديل وابنه واختبره، وقدم خطوات التثبيت والاستعادة والنتائج الفعلية.
اذكر الاختبارات التي لم تُنفّذ بوضوح؛ لا تكتفِ بالكود الوهمي.
```

يلزم الوصول إلى الشيفرة المصدرية أو واجهة تعديل أو نقطة توسعة تم التحقق منها. هذه ليست رقعة عامة تعمل فوراً مع جميع الألعاب. في اللعب الجماعي يجب أن تتطابق محاكاة الخادم مع تنبؤ العميل.

`goldsrc-stock`: HL1 / GoldSrc · `classic-bhop`: stock limiter disabled.

## نطاق الترجمة

هذه المقدمة والطلب الموجه إلى الذكاء الاصطناعي بالعربية. يوجد دليل تفصيلي للبدء بالإنجليزية، أما أدلة المحركات المتخصصة فما زالت في معظمها بالروسية. اطلب ترجمتها مع الحفاظ على المعادلات والوحدات ومتطلبات الاختبار. راجع VALIDATION.md لمعرفة ما تم اختباره فعلاً.
