Примеры не содержат полноценную систему crouch/fall damage/step-up для каждого движка. Для этих подсистем есть отдельные инструкции интеграции. Формулы не означают полного совпадения BSP-коллизий и физики HL1.

Команды воспроизведения находятся в [docs/TESTING.md](docs/TESTING.md). Официальный portable Godot использовался только для локальной проверки и не включён в пакет. Перед запуском его SHA-256 был сопоставлен с digest официального релиза.
